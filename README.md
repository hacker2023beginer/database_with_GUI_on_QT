# 🗄️ Database with GUI on Qt

[![License: MIT](https://shields.io)](https://opensource.org)
[![Qt Version](https://shields.io)](https://qt.io)
[![Language](https://shields.io)]()

**Database with GUI on Qt** — это кроссплатформенное десктопное приложение с графическим интерфейсом для удобного взаимодействия с реляционными базами данных. Проект демонстрирует интеграцию графических компонентов Qt с базами данных, реализацию полноценного CRUD-функционала и обработку пользовательских транзакций в GUI-потоке без зависания интерфейса.

## ✨ Основные возможности

* **Полный CRUD-функционал:** Добавление, просмотр, редактирование и удаление записей базы данных прямо через графические таблицы (`QTableView` / `QTableWidget`).
* **Интерактивные фильтры и поиск:** Динамическая фильтрация строк по ключевым словам, датам или категориям без необходимости вручную писать SQL-запросы.
* **Валидация данных:** Автоматическая проверка корректности ввода на стороне интерфейса (регулярные выражения, типы данных, проверка пустых полей) перед отправкой запроса в БД.
* **Безопасное соединение:** Поддержка сохранения конфигурации подключения (хост, порт, учетные записи) и безопасного тестирования связи перед открытием сессии.

## 🧠 Архитектура и архитектурные выводы

В процессе разработки GUI-приложений для работы с СУБД на фреймворке Qt сформировались следующие ключевые архитектурные решения:
1. **Разделение логики (Model-View Architecture):** Использование встроенных моделей Qt (таких как `QSqlTableModel` или `QSqlQueryModel`) позволяет автоматически синхронизировать данные в базе с их отображением на UI, минимизируя ручную перерисовку виджетов.
2. **Асинхронные тяжелые запросы:** Выполнение сложных SQL-запросов (или работа с удаленной базой данных) вынесено в отдельные рабочие потоки через `QThread` или `QtConcurrent`, чтобы главный GUI-поток оставался отзывчивым и интерфейс не «фризился».
3. **Безопасность транзакций:** Важные операции изменения данных обернуты в SQL-транзакции (`BEGIN`, `COMMIT`, `ROLLBACK`), что исключает появление битых данных при случайных ошибках или закрытии приложения.

## 🛠️ Технологический стек

* **Framework:** Qt (C++ Qt Widgets)
* **Язык разработки:** C++ 
* **Базы данных (на выбор):** SQLite (локальная), PostgreSQL / MySQL (удаленные)
* **Сетевой уровень/Драйверы:** `QSqlDatabase`, `QSqlQuery`
* **Система сборки:** CMake / QMake (для C++)

---

## 💻 Требования к окружению

* Установленный **Qt SDK** (рекомендуется версия 5.15 или 6.x)
* Компилятор с поддержкой C++17 (GCC, Clang, MSVC)
* Соответствующие СУБД драйверы (например, `qsqlpsql` для PostgreSQL, `qsqlmysql` для MySQL)

## 🚀 Сборка и локальный запуск

### Вариант 1: Сборка на C++ (CMake)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd database_with_GUI_on_QT
   ```
2. Создайте директорию сборки и скомпилируйте проект:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```
3. Запустите исполняемый файл:
   ```bash
   ./database_app
   ```

### Вариант 2: Запуск на Python (PyQt / PySide)
1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com
   cd database_with_GUI_on_QT
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите скрипт:
   ```bash
   python main.py
   ```

## 🔧 Конфигурация подключения

В приложении предусмотрена гибкая настройка через конфигурационный файл (`config.ini` / `settings.json`) или диалоговое окно при старте:

```ini
[Database]
Driver=QSQLITE ; Или QPSQL, QMYSQL
DatabaseName=app_database.db
Host=localhost
Port=5432
Username=admin
Password=secret_pass
```
